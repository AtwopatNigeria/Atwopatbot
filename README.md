# 🤖 ATWOPAT Telegram Verification Bot System

## 📌 About This Project

This is a secure Telegram bot system built for the **Association Of Table Water Operators And Technicians (ATWOPAT)**.

It provides a full digital membership verification system connected to Google Sheets.

## 🚀 Features

### 👤 Member Features
- Check membership status using Member ID
- View full profile details
- See passport photo
- View state group link
- Contact support directly from bot

### 🛠 Admin Features
- Secure admin login using access codes
- Update member status (Active / Pending / Suspended / Rejected)
- Track admin actions
- View logs of all changes

### 📢 Group Management
- Auto welcome new members
- Anti-link protection system
- Warning system (3 warnings = auto ban)
- Temporary restrictions for violations

---

## 🧠 System Architecture

- Telegram Bot (Node.js + Telegraf)
- Google Sheets (Main Database)
- Google Apps Script (API Layer)
- Render Cloud Hosting (24/7 uptime)

---

## 🔐 Security

- Environment variables used for all secrets
- No sensitive data stored in GitHub
- Admin access controlled via secure codes
- Logs stored for accountability
